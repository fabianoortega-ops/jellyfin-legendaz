Legendaz

Search and download subtitles directly from the Jellyfin player — integrated with Bazarr and OpenSubtitles.

One button. Search. Download. Done.

Jellyfin 10.11.x Requires JavaScript Injector Requires Bazarr 25 languages Open Source MIT
⚡ Install Now ⬡ GitHub

✨ Features

🔍

In-Player Search

Search button in the OSD, right next to the subtitle button — no leaving the player.

⬇️

One-Click Download

Click a result and the subtitle is downloaded, the library updated, and the track activated automatically.

🎯

Auto-Select

After download, the new subtitle is automatically selected — no manual CC menu interaction needed.

🌍

25 Languages

Interface language auto-detected from your browser or Jellyfin profile preferences.

🔗

Bazarr Integration

Works through the Bazarr plugin — searches OpenSubtitles, Subscene, and all your configured providers.

🚀

Hot Reload

UI updates via git push — no server restart needed after changing the player script.

📦 Installation

1

Install JavaScript Injector (required)

Go to Dashboard → Plugins → Repositories → + and add:

https://raw.githubusercontent.com/n00bcodr/jellyfin-plugins/main/10.11/manifest.json

Then go to Catalog, find JavaScript Injector and install it. Restart Jellyfin.

🐳 Docker / TrueNAS: if you see a permission error on index.html, also install File Transformation (v2.2.1.0+).
2

Install Bazarr plugin (required)

Go to Dashboard → Plugins → Repositories → + and add the Bazarr Jellyfin plugin repository. Install and configure it with your Bazarr URL and API key.

3

Install Legendaz

Go to Dashboard → Plugins → Repositories → + and add:

https://fabianoortega-ops.github.io/jellyfin-legendaz/manifest.json

Go to Catalog → Subtitles, find Legendaz and install it.

4

Restart Jellyfin

Restart once to load all plugins. The 🔍 button will appear in the player OSD, next to the subtitle button.
